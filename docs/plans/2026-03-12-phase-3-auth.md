# Phase 3 Auth Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete phase 3 for Joint with JWT login, Spring Security request protection, permission checks, and current-user access on the existing system module APIs.

**Architecture:** Keep the current layered Spring Boot structure and add a thin auth module plus reusable security infrastructure under `common/security` and `config`. Authentication stays stateless with JWT claims carrying role codes; permission resolution stays database-backed so controller authorization reflects current RBAC data.

**Tech Stack:** Spring Boot 4, Spring Security 7, MyBatis-Plus, jjwt, BCrypt, MockMvc tests, JUnit 5
